02采集流程

  1. 枚举论文全集访问期刊官网年度目录页 10 个、期目录页 58 个，解析标题、作者、年期、页码与 DOI，得到 682 篇论文的基准清单。
  2. 按刊号规则拼接知网地址知网文献号形如 ZJJW + 年份 + 期号 + 序号（如 ZJJW202101001），按期顺序探测，命中即解析，连续 3 次未命中即判定该期结束。
  3. 解析知网详情页从页面内嵌的服务端渲染数据中还原结构化字段：被引量、下载量、作者列表、作者单位、关键词、摘要。共获得 801 条知网记录（含稿约、获奖公告等非论文条目）。
  4. 下载论文 PDF 并抽取全文682 份 PDF 全部下载成功；用 pdftotext 抽取文本后，定位“参考文献”标题并统计编号条目，同时抓取摘要、关键词与基金标注。
  5. 题名匹配与合并在同一期范围内用编辑距离匹配官网标题与知网标题（阈值 0.82，另设前缀包含规则处理副标题截断），681 篇匹配成功。
  6. 清洗与校验统一全角标点、修复 PDF 抽取产生的异体字符、去除基金文本中的多余标签；随机抽取 5 篇回源复核，被引、下载、参考文献三项全部一致。

# 1) 按期探测知网文献号，命中即解析内嵌 JSON
def crawl_issue(y, i):
    out, misses = [], 0
    for seq in range(1, 40):
        url = "https://wap.cnki.net/touch/web/Journal/Article/ZJJW{}{}{:03d}.html".format(y, i, seq)
        d = extract(fetch(url))
        if not d:
            misses += 1
            if misses >= 3: break      # 连续 3 次未命中 → 该期结束
            continue
        misses = 0
        out.append({"fileName": d["fileName"], "title": d["title"],
                    "quoteFrequency": d["quoteFrequency"],
                    "downloadCount": d["downloadCount"]})
        time.sleep(0.05)               # 限速，单线程 4 并发
    return out

# 2) 从 PDF 全文统计参考文献条数（取条目最多的“参考文献”标题位置）
def count_refs(text):
    best = (0, 0)
    for m in re.finditer(r"参\s*考\s*文\s*献", text):
        nums = [int(x) for x in re.findall(r"\[\s*(\d{1,3})\s*\]", text[m.start():m.start()+20000])]
        if nums:
            covered = len({k for k in range(1, max(nums)+1) if k in set(nums)})
            best = max(best, (max(nums), covered))
    return best[0]
